
# Ventartelyen - API REST

## Descripción del proyecto
Ventartelyen es un proyecto académico desarrollado para gestionar productos, servicios y usuarios mediante una API REST.

El sistema permite administrar la información de una tienda virtual y gestionar el acceso de los usuarios mediante autenticación.

## Tecnologías utilizadas
- Node.js
- Express.js
- JavaScript
- MySQL compatible con TiDB Cloud
- bcryptjs
- JSON Web Token (JWT)
- Git y GitHub
- Render

## Funcionalidades
- Registro de usuarios.
- Inicio y cierre de sesión.
- Autenticación mediante JWT.
- Protección de contraseñas mediante bcrypt.
- Gestión de usuarios.
- CRUD de productos.
- CRUD de servicios.
- Control de acceso para administradores.
- Conexión con base de datos en la nube.

## Publicación
API REST: https://ventartelyen-api.onrender.com

Tienda virtual: https://vocal-semolina-ac3e07.netlify.app

## Base de datos
Se utiliza TiDB Cloud, compatible con MySQL, para almacenar usuarios, productos, servicios y sesiones.
